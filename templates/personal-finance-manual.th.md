# คู่มือการใช้งาน BUU Personnel Finance

ระบบติดตามการเงินส่วนบุคคลและวางแผนเกษียณสำหรับบุคลากรมหาวิทยาลัยบูรพา
(ทักษะ `personal-finance` ใน nk-work-kit สำหรับ Claude Code)

> English version: `personal-finance-manual.en.md`

---

## 1. ระบบนี้ทำอะไรให้คุณ

- **รวมรายรับรายจ่ายไว้ที่เดียว** จากรายการเดินบัญชีธนาคารและใบแจ้งยอดบัตรเครดิต
  โดยตรวจยอดกับยอดรวมที่ธนาคารพิมพ์ไว้ในเอกสารทุกฉบับก่อนบันทึก
- **จัดหมวดหมู่ให้อัตโนมัติ** เช่น เงินเดือน บำนาญ ค่าอาหาร ค่าน้ำมัน และเรียนรู้กฎใหม่ที่คุณเพิ่ม
- **ติดตามเงินที่มหาวิทยาลัยต้องคืนคุณ** (เงินทดรองจ่าย ค่าเล่าเรียนบุตร) จนกว่าจะได้รับเงินคืน
- **ดูภาพรวม**: มูลค่าทรัพย์สินสุทธิ งบประมาณรายเดือน กำหนดชำระบัตรเครดิต และหนี้บ้าน
- **วางแผนเกษียณ**: คำนวณวันเกษียณจากวันเกิด ประมาณเงินที่ต้องมี เทียบกับเงินที่คาดว่าจะมี
  และบอกว่าต้องเก็บเพิ่มเดือนละเท่าใด
- **แดชบอร์ด** สรุปเป็นกราฟและตาราง (แสดงเฉพาะยอดรวม ไม่แสดงเลขบัญชี)

ข้อมูลทั้งหมดอยู่ใน **Google Sheet ส่วนตัวของคุณเอง** ไม่มีใครเห็นนอกจากคุณ
Claude เป็นผู้ช่วยที่คุยกับคุณ นำเข้าข้อมูล และอธิบายตัวเลข

## 3. เริ่มต้นใช้งานครั้งแรก (ประมาณ 15 นาที)

เปิด Claude Code แล้วพิมพ์ว่า **"ตั้งค่าระบบการเงินส่วนตัว"** Claude จะพาทำทีละขั้น:

1. **ลงชื่อเข้าใช้ Google** – เบราว์เซอร์จะเปิดขึ้นมา ให้เลือกบัญชี @buu.ac.th และกดอนุญาต
   (ระบบขอสิทธิ์เฉพาะ Google Sheets)
2. **ตอบคำถามสั้น ๆ** – วันเกิด สถานะ (ข้าราชการ / พนักงานมหาวิทยาลัย / เปลี่ยนสถานภาพ)
   ธนาคารและบัตรเครดิตที่ใช้ หนี้บ้าน กองทุนและประกัน และค่าใช้จ่ายต่อเดือนที่อยากมีหลังเกษียณ
3. **สร้าง Google Sheet** ชื่อ "Personal Finance" – Claude จะส่งลิงก์ให้
4. **เลือกโฟลเดอร์เก็บเอกสาร** เช่น `~/Finance` ระบบจะสร้างโฟลเดอร์ย่อย
   `Statements/` `Tax/` `Insurance/`
5. **นำเข้าครั้งแรก** – นำไฟล์ PDF ใส่ใน `Statements/` (ตั้งชื่อไฟล์อย่างไรก็ได้)
   แล้วบอก Claude ว่า **"นำเข้าสเตทเมนต์"** ถ้าพบบัญชีที่ยังไม่รู้จัก Claude จะถามชื่อบัญชีแล้วเพิ่มให้

## 4. ใช้งานประจำเดือน (ประมาณ 10 นาที)

| เมื่อไร | ทำอะไร | พูดกับ Claude ว่า |
|---|---|---|
| ได้ใบแจ้งยอดบัตรเครดิตทางอีเมล | บันทึก PDF ลง `Statements/` | "นำเข้าสเตทเมนต์" |
| ทุก 1–3 เดือน | ขอรายการเดินบัญชีจาก Krungthai NEXT | "นำเข้าสเตทเมนต์" |
| หลังนำเข้า | ตรวจรายการที่ยังไม่มีหมวด | "รายการไหนยังไม่มีหมวดหมู่" |
| เมื่อสำรองจ่ายแทนมหาวิทยาลัย | บันทึกเงินทดรองจ่าย | "บันทึกเงินทดรองจ่ายโครงการ ... จำนวน ..." |
| เมื่อได้รับเงินคืน | ปิดรายการ | "เงินทดรองจ่าย ADV-003 ได้คืนแล้ว" |
| ทุกเดือนหรือไตรมาส | อัปเดตมูลค่ากองทุน | "มูลค่า RMF ตอนนี้ ... บาท" |
| เมื่อต้องการดูภาพรวม | สร้างแดชบอร์ด | "อัปเดตแดชบอร์ดการเงิน" |

**ทำไมบางรายการเป็น "Unspecified QR/PromptPay"** – รายการเดินบัญชีของธนาคารบอกเพียงว่าโอน
พร้อมเพย์หรือสแกน QR แต่ไม่บอกชื่อร้าน บอก Claude ว่าเบอร์หรือบัญชีนั้นคือใคร
ระบบจะสร้างกฎให้จัดหมวดอัตโนมัติในครั้งต่อไป

## 5. เอกสารที่รองรับ

| ธนาคาร | เอกสาร | วิธีได้มา |
|---|---|---|
| กรุงไทย | รายการเดินบัญชีออมทรัพย์ / กระแสรายวัน (PDF) | แอป Krungthai NEXT หรือขอที่สาขา |
| กรุงไทย | รายการบัญชีสินเชื่อบ้าน (PDF) | เช่นเดียวกัน (ใช้อัปเดตยอดหนี้บ้านและดอกเบี้ย) |
| UOB | ใบแจ้งยอดบัตรเครดิตอิเล็กทรอนิกส์ (PDF) ทุกบัตรในฉบับเดียว | อีเมลรายเดือน |

ธนาคารอื่น: พิมพ์หรือวางรายการลงแท็บ Transactions ได้เอง หรือขอให้ผู้ดูแลเพิ่มตัวอ่านเอกสาร

**ไฟล์ที่มีรหัสผ่าน** – ไม่ต้องปลดล็อกเอง ระบบจะถามรหัสผ่านตอนนำเข้า
และ **ไม่บันทึกรหัสผ่านไว้ที่ใดเลย** โปรดอย่าเก็บไฟล์ที่ปลดล็อกแล้วไว้ในโฟลเดอร์ที่ซิงก์ขึ้นคลาวด์

## 6. Google Sheet มีอะไรบ้าง

| แท็บ | เนื้อหา |
|---|---|
| Net Worth | ทรัพย์สินสุทธิ: เงินฝาก + การลงทุน + เงินที่จะได้คืน − บัตรเครดิต − หนี้ |
| Budget | งบประมาณรายหมวดเทียบกับที่ใช้จริงในแต่ละเดือน |
| Retirement | ประมาณการเงินจนถึงอายุที่วางแผน พร้อมกราฟ "เงินที่คาดว่าจะมี" เทียบ "เงินที่ต้องมี" |
| Transactions | รายการทั้งหมด (ระบบเพิ่มให้ คุณแก้หมวดได้) |
| Card | ยอดบัตรเครดิตแต่ละรอบ วันครบกำหนด และชำระครบหรือไม่ |
| Advances | เงินทดรองจ่าย / เงินที่รอเบิกคืน |
| Tax | สรุปแบบ ภ.ง.ด.90/91 ที่ยื่นแล้ว |
| Mortgage | หนี้บ้าน ดอกเบี้ยที่จ่ายปีนี้ และประมาณการวันปลดหนี้ |
| Investments | มูลค่ากองทุน RMF / ThaiESG / กองทุนสำรองเลี้ยงชีพ |
| Rules | กฎจัดหมวดหมู่ (แก้ไขหรือเพิ่มได้) |
| Accounts | รายชื่อบัญชีและบัตร พร้อมยอดล่าสุด |
| Categories | รายชื่อหมวดหมู่ |
| Settings | วันเกิด วันเกษียณ บำนาญ อัตราเงินสะสม เงินเฟ้อ ผลตอบแทน เป้าหมายใช้จ่าย |

สีในชีต: **ตัวอักษรสีน้ำเงิน** = ค่าที่คุณกรอก/ปรับได้ **สีเขียว** = ดึงมาจากแท็บอื่น
**พื้นเหลือง** = ยังต้องกรอก ตัวเลขอื่นเป็นสูตร ไม่ควรพิมพ์ทับ

## 7. การวางแผนเกษียณ

- **วันเกษียณ** = 30 กันยายนของปีงบประมาณที่คุณอายุครบ 60 ปี (คำนวณให้อัตโนมัติ)
- กรอกในแท็บ Settings: บำนาญต่อเดือน (ถ้ามี) อัตราเงินสะสมกองทุนสำรองเลี้ยงชีพ
  เงินที่อยากใช้ต่อเดือนหลังเกษียณ (มูลค่าปัจจุบัน) และประกันบำนาญ (ถ้ามี)
- กรอกในแท็บ Retirement: เงินสะสม+สมทบกองทุนต่อเดือน เงินซื้อ RMF/ThaiESG ต่อปี
  ค่าการศึกษาบุตร และรายได้หลังเกษียณ (เช่น งานที่ปรึกษา)
- ดูผลที่มุมขวาบน: เงินที่คาดว่าจะมี ณ วันเกษียณ เงินที่ต้องมี ส่วนขาด/ส่วนเกิน
  ต้องเก็บเพิ่มเดือนละเท่าใด และเงินจะพอใช้ถึงอายุเท่าไร
- ลองถาม Claude เช่น **"ถ้าซื้อ RMF ปีละ 100,000 จะเป็นอย่างไร"** หรือ
  **"ถ้าย้ายงานก่อนอายุ 55 กองทุนสำรองเลี้ยงชีพจะเสียภาษีไหม"**

> ตัวเลขเป็นการประมาณการเพื่อวางแผนเท่านั้น โปรดยืนยันสิทธิและเงื่อนไขกับกองการเจ้าหน้าที่
> ผู้จัดการกองทุน หรือกรมสรรพากรก่อนตัดสินใจ

## 8. ภาษี

- บันทึกตัวเลขจากแบบ ภ.ง.ด.90/91 ที่ยื่นแล้วในแท็บ Tax เพื่อดูอัตราภาษีจริงและค่าลดหย่อนที่ใช้
- ข้อควรตรวจ: เงินสะสมกองทุนสำรองเลี้ยงชีพส่วนที่เกิน 10,000 บาทได้ใช้สิทธิครบหรือไม่
  ค่าลดหย่อนบุตร ดอกเบี้ยบ้าน และประกัน
- RMF, ThaiESG และเบี้ยประกันต้องจ่าย **ภายใน 31 ธันวาคม** จึงใช้ลดหย่อนปีนั้นได้

## 9. ใช้งานหลายเครื่องด้วย Google Drive (ไม่บังคับ)

ถ้าใช้ rclone เชื่อม Google Drive อยู่แล้ว:

1. ติดตั้งคำสั่งซิงก์: `install -m 755 <plugin>/scripts/aisync ~/.local/bin/aisync`
2. ถ้าโฟลเดอร์การเงินไม่ได้อยู่ใต้ `~/aiSpace` ให้เพิ่มใน `~/.config/nk-work-kit/.env`:
   `AISYNC_ROOT=~/Finance` (และ `AISYNC_REMOTE=ชื่อ remote:` ถ้าไม่ได้ชื่อ `GDrive`)
3. บอก Claude ว่า **"เปิดการซิงก์โฟลเดอร์การเงินกับ Google Drive"**
   ระบบจะซิงก์ทุกครั้งที่เริ่มและจบการใช้งาน Claude ในโฟลเดอร์นั้น
4. เครื่องใหม่: ติดตั้ง rclone + ปลั๊กอิน แล้วรัน `aisync` ในโฟลเดอร์เดียวกันหนึ่งครั้ง
   และลงชื่อ Google ใหม่ด้วย `pf.py auth` (ข้อมูลการลงชื่อไม่ถูกซิงก์ขึ้น Drive)

## 10. ความเป็นส่วนตัวและความปลอดภัย

- Google Sheet เป็นของคุณ ไม่ได้แชร์ให้ใคร Claude ไม่ส่งข้อมูลออกไปที่อื่นถ้าคุณไม่ได้ขอ
- รหัสผ่านไฟล์ PDF ไม่ถูกบันทึก ไฟล์ลงชื่อเข้าใช้ (`pf-token.json`) อยู่ในเครื่องคุณเท่านั้น ห้ามแชร์
- แดชบอร์ดแสดงเฉพาะยอดรวม ไม่มีเลขบัญชีหรือชื่อผู้รับเงิน
- ถ้าเลิกใช้: ลบ Google Sheet และลบไฟล์ `~/.config/nk-work-kit/pf-token.json`

## 11. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|

| นำเข้าซ้ำกลัวข้อมูลซ้ำ | ไม่ซ้ำ ระบบเพิ่มเฉพาะรายการใหม่เสมอ |

## 12. คำสั่งสำหรับผู้ใช้ขั้นสูง

```bash
pf.py auth                      # ลงชื่อเข้าใช้ Google
pf.py setup --dob 1980-01-15 --save
pf.py init-folder ~/Finance --save [--sync]
pf.py add-account --id KTB-CUR --name "บัญชีกระแสรายวัน" --type Bank --institution "Krung Thai" --number 1234567890
pf.py import [--dry-run]
pf.py suggest-budget [--overwrite]
pf.py dashboard [--html]
pf.py status
```

`pf.py` คือ `uv run <plugin>/scripts/pf.py` · ไฟล์ตั้งค่า `~/.config/nk-work-kit/.env`
(`PF_SHEET_ID`, `PF_DIR`, `OBSIDIAN_VAULT`, `PF_DASHBOARD`, `AISYNC_*`)
